- Wii Remote Connect -

Wiiリモコンの自動接続サンプルソフト  (for Microsoft Bluetooth Stack)

Sample software for Wii remote  auto-connection  (for Microsoft Bluetooth Stack)


このソフトは、WiiリモコンをBluetoothでPCに接続するためのソフトです。
接続した後は、他のWiiリモコン用ソフトを使うことができます。


MicrosoftのBluetoothスタックソフトにのみ対応しています。

東芝製Bluetoothスタックソフトや、WIDCOMMのBluetoothスタック、Bluesoleil等には対応していません。
