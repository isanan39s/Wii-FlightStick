# Wiiリモコン技術詳細 (Technical Deep Dive)

本ドキュメントは、Wiibrew Wikiの調査に基づき、Wiiリモコンの低レイヤー通信・制御に関する詳細な仕様をまとめたものである。

## 1. Data Reporting (入力レポート構造)
Wiiリモコンからホストへ送信されるデータは、**Report ID** を用いて種類が識別される。

### 主要なレポートIDと内容
| Report ID | 内容 | 特徴 |
| :--- | :--- | :--- |
| `0x03` | **Button Mask** | ボタンの状態を2バイトのビットマスクで送信。 |
| `0x04` | **Motion Data** | 加速度計およびジャイロスコープの数値を送信。 |
| `0x05` | **IR Data** | 赤外線センサーからのポインティング情報を送信。 |
| `0x06` | **Status** | バッテリー残量や接続状態などの補助情報。 |

### ボタンマスクのビット割り当て (例)
*   Bit 0: D-Pad Left
*   Bit 1: D-Pad Right
*   Bit 2: D-Pad Down
*   Bit 3: D-Pad Up
*   Bit 4: Plus (+)
*   Bit 5: Minus (-)

## 2. Accelerometer (加速度センサー仕様)
モーション検知の核心となるデータ構造。

### データ形式
*   **3軸構成:** X, Y, Z の各軸に対して独立した値を報告。
*   **データ型:** 各軸は **16ビット（2バイト）の符号付き整数** で表現される。
    *   これにより、重力方向に対する加速だけでなく、前後の動きや左右の揺れを正確に捉えることが可能。

### センサーフュージョン
単一の加速度計データだけでなく、以下のデータを組み合わせることで空間内の正確な座標・向きを算出する。
1.  **Accelerometer:** 重力と移動の基本加速。
2.  **Gyroscope:** 角速度（回転の速さ）による姿勢変化の補正。
3.  **IR (Infrared):** 空間内での絶対的な位置情報の補完。

## 3. Memory and Registers (メモリマップ)
リモコン内部には設定を保持する仮想的なメモリ領域があり、ホストはこの領域に対して書き込み・読み取りを行うことでデバイスの挙動を制御する。

### 主要なアドレス範囲
| アドレス範囲 | 内容 | 用途 |
| :--- | :--- | :--- |
| `0xA40000 - 0xA400FF` | **拡張コントローラー設定** | Nunchuk等の周辺機器のID、接続状態、固有設定を管理。 |
| `0xA60000 - 0xA600FF` | **MotionPlus / ジャイロ設定** | モーションセンサーの感度、動作モード、特定のゲーム用プリセットなどを制御。 |
| `0xB00000 - 0xB00033` | **IRカメラ設定** | 赤外線センサーの輝度、反応範囲、感度などのパラメータを調整。 |

### 制御フローのイメージ
1.  **ホスト:** 特定のアドレス（例：`0xA600xx`）への書き込み命令を含むパケットを作成。
2.  **通信:** Bluetooth HIDパイプを通じてリモコンへ送信。
3.  **リモコン:** 受信した値を内部EEPROMに保存し、センサーの動作パラメータを即座に変更。
