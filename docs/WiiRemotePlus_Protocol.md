# Wiiリモコンプラス 通信プロトコル仕様まとめ

本ドキュメントは、Wiiリモコン（およびWiiリモコンプラス）の無線通信プロトコルに関する技術的な調査結果をまとめたものである。

## 1. 基本概要
*   **通信方式:** Bluetooth (標準Bluetooth技術を使用)
*   **ベースチップ:** Broadcom BCM2042 SoC
*   **主な役割:** 加速度計、ジャイロスコープ、赤外線（IR）センサー、ボタン入力の統合ハブ。

## 2. 通信基盤とHIDインターフェース
WiiリモコンはBluetoothプロトコルを介してホストと通信するが、標準的なHIDデバイスとは異なる挙動を示す。

### Bluetooth L2CAP PSM
*   **0x11:** コントロールパイプ（接続管理など）
*   **0x13:** データパイプ（入力・出力データのやり取り）

### HIDプロトコルの特殊性
*   Wiiリモコンは標準的なHID記述子（Descriptor）を完全には遵守していない。
*   レポートの長さのみを定義し、中身のデータ構造については「未定義」としているため、OS標準ドライバでは動作せず、専用の解析ロジックが必要となる。

## 3. データ構造 (Reports)

### 入力レポート (Input Reports: リモコン → ホスト)
リモコンから送信されるバイナリパケット。主な内容は以下の通り。

#### A. ボタン状態 (Button Mask)
*   **形式:** 2バイトのビットマスク（ビッグエンディアン）。
*   **主要なビット割り当て:**
    *   Bit 0: D-Pad Left
    *   Bit 1: D-Pad Right
    *   Bit 2: D-Pad Down
    *   Bit 3: D-Pad Up
    *   Bit 4: Plus (+)
    *   Bit 5: Minus (-)

#### B. モーションデータ (Motion Data)
加速度計およびジャイロスコープの数値を送信。
*   **加速度計 (Accelerometer):** X, Y, Z の3軸（各16ビット符号付き整数）。
*   **ジャイロスコープ (Gyroscope):** Wiiリモコンプラス特有のデータ。X, Y, Z の3軸（各16ビット符号付き整数）。

#### C. 赤外線 (IR) データ
ポインティング用の赤外線センサーからの反射強度や位置情報を含む。

### 出力レポート (Output Reports: ホスト → リモコン)
ホストからリモコンへ送られる制御命令。

*   **LED制御:** プレイヤー識別用LEDの点灯・消灯、色、点滅パターンの指定。
*   **スピーカーデータ:** 音声データのストリーム送信。
*   **振動 (Rumble):** モーターの強度と方向の制御。

## 4. メモリマップと内部制御
リモコン内のEEPROMには特定の機能設定が格納されており、これらへのアクセスによってデバイスの状態を管理する。

| アドレス範囲 | 内容 |
| :--- | :--- |
| `0xA40000 - 0xA400FF` | **拡張コントローラー設定:** Nunchuk等の周辺機器のIDや状態を保存。 |
| `0xA60000 - 0xA600FF` | **Wii MotionPlus / ジャイロ設定:** モーションセンサーの感度や動作モード。 |
| `0xB00000 - 0xB00033` | **IRカメラ設定:** 赤外線センサーの輝度・感度などのパラメータ。 |

## 5. 実装上の注意点
*   **符号付き整数の処理:** センサーデータ（特に負の値）を扱う際は、16ビット符号付き整数として正しくデコードする必要がある。
*   **サンプリングレート:** モーションデータは非常に高い頻度で送信されるため、受信側では最新のパケットを常に上書きするポーリング処理が基本となる。
*   **独自ドライバの必要性:** 標準HIDプロトコルを「悪用」しているため、独自のパケット解析ロジックの実装が必須である。
